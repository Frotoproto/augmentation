# Implementation Plan: Premium Redesign

## Goal
Transform the site into a premium, minimalist experience. Remove all "AI slop" (gradients, heavy shadows, complex effects) and transition to a clean, high-end aesthetic using Inter Thin as the primary typeface.

## Background and context
- Current site uses `Turnpike` font, heavy gradients, complex box shadows, and a custom cursor.
- The design is dark-themed with a "grain" overlay.
- The goal is to strip back the visual noise and adopt a "premium" look.

## Specialist Team
- **Orchestrator**: Manages the transition and ensures consistency.
- **Frontend Engineering**: Implements the new CSS token system and typography updates.
- **Reviewer**: Validates the visual output against the "no AI slop" constraint.

## Implementation Steps
1. **Typography**: Replace `Turnpike` with `Inter` (Thin weight, 100). Update `@font-face` or import via Google Fonts.
2. **CSS Token Cleanup**: 
   - Remove all gradients (e.g., in `nav h1`, `timeline__spine-fill`, `player__scrubber-fill`).
   - Replace with solid, high-contrast colors (e.g., pure white/black or subtle grays).
   - Remove all box shadows and complex blur effects.
   - Simplify the cursor to a minimal dot.
3. **Layout Refinement**: 
   - Tighten spacing and remove decorative elements like the spine sheen or hover-sheen on players.
   - Ensure the layout remains responsive but feels more "architectural" and less "digital-product-y".
4. **Verification**: Run `repo.css_audit` to ensure no legacy gradients or shadows remain.

## Verification
- Visual inspection of `index.html` via `repo.preview_page`.
- CSS audit to confirm removal of all gradients and shadows.

## Risks
- Removing all shadows might make the UI feel "flat" or hard to read; will use subtle borders instead.
- Removing the custom cursor might affect the "premium" feel; will ensure the native cursor is styled appropriately.
